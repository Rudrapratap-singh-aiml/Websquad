🏨🎓 **Introducing Our University Project – LPU Hotel: Hotel Guest Service Request Portal!**

We are excited to present our university project, developed as part of our academic journey at **Lovely Professional University (LPU)**! 🚀

💡 **About the Project:**

LPU Hotel is a web-based Hotel Guest Service Request Portal designed to simplify communication between hotel guests and staff, making hotel service management more organised and efficient.

✨ **Key Features:**

👤 **1. Guest Dashboard**
- Guest login using name and room number.
- Access hotel services.
- Submit service requests.

🛎️ **2. Service Request System**
- Housekeeping services.
- Room service.
- Maintenance requests.
- Front desk assistance.
- Normal and urgent priority options.

📋 **3. Request Tracking**
- View submitted requests.
- Track request status.
- Monitor pending and ongoing requests.

👨‍💼 **4. Staff Dashboard**
- Staff login interface.
- Department selection.
- View guest requests.
- Update request status.
- Manage service operations.
